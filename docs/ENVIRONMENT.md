# Environment and secrets

## Variables

| Variable | Required | Used by | Notes |
|---|---:|---|---|
| `SUPABASE_URL` | yes | `lib/db.ts` | HTTPS Supabase project URL; never put the pooler URL here. |
| `SUPABASE_SERVICE_ROLE_KEY` | yes | `lib/db.ts` | Server-only; bypasses RLS. Never expose to browser. |
| `SESSION_SECRET` | yes | `lib/session.ts` | At least 32 random characters; signs the `ca1_session` cookie. |
| `APIFY_API_TOKEN` | yes for practical verification | `lib/apify.ts`, `lib/grading.ts` | Server-side token used to inspect runs/datasets/source. |
| `NEXT_PUBLIC_APP_URL` | yes in deployment | links/integrations | Public application URL. Only variables prefixed `NEXT_PUBLIC_` may be client-visible. |
| `GITHUB_ANALYSIS_TOKEN` | optional but recommended | `lib/github-analysis.ts` | Authenticated GitHub API calls improve rate limits. |
| `GROQ_API_KEY` | optional unless AI evaluation used | `lib/groq.ts` | Primary Groq key. |
| `GROQ_API_KEY_BACKUP1` | optional | `lib/groq.ts` | Used after primary quota/rate failure. |
| `GROQ_API_KEY_BACKUP2` | optional | `lib/groq.ts` | Used after backup 1 quota/rate failure. |
| `GROQ_CA3_MODEL` | optional | `lib/ca3-ai-evaluation.ts` | Defaults to `qwen/qwen3.8-27b`; the old llama model is intentionally replaced. |
| `TASK3_SHEET_CSV_URL` | required for CA1 sessions | session creation | Public CSV export URL; fetched and frozen into each session. |
| `CRON_SECRET` | deployment-dependent | `/api/cron/verify` | If configured, protects scheduled verification. Check route behavior before deployment. |

## Secret handling

- `.env.local` is ignored and must never be committed.
- API keys are hashed/encrypted before storage as described in `lib/api.ts` and `lib/api-key-vault.ts`.
- The student exam API key is shown once when generated; only its hash/prefix are stored.
- The Supabase service-role key gives full database access and must remain server-only.
- If a key has been pasted into chat, a document, a screenshot, or a commit, rotate it immediately.
- Do not print environment values in diagnostics. Redact URLs containing database passwords.

## Generated/runtime data

- `public/corpus/` is committed static exam data generated by `scripts/generate-corpus.ts`.
- `scripts/task3-spreadsheet.csv` is generated locally and normally not used as the runtime source after the Google Sheet is configured.
- Supabase Storage bucket `ca3-artifacts` is private; file routes issue short-lived signed URLs.
